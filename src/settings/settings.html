Data providers

Phase 1 ships with a built-in demo provider only - every figure it produces is placeholder data and is labelled DEMO DATA in the popup. Real providers are added by registering a module in src/services/providers/. API keys belong in this page (stored locally in browser.storage.local), never in the source code.

Privacy

All settings, caches and scan results stay on this machine. Nothing is uploaded and there is no account. This extension never requests, stores or reads private keys, seed phrases, wallet passwords or signing credentials, and it cannot execute trades - it has no wallet code at all.
